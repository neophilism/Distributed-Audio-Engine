# Current-position endpoint player

`EndpointProgramPlayer` connects the compiled timeline, authenticated private asset resolver, endpoint rights adapter, ciphertext transport, complete-file authentication/decoding and bounded PCM sink. Applications call `pump` often enough to maintain the short sink queue. It has no song-selection, seek or personalized insertion operation.

Each pump first finds the live frame. It authorizes the asset before fetching, authenticates the complete bounded waveform, validates private sample metadata against the program and resolves the current target again after asynchronous work. If delivery crossed into a different asset, it discards the obsolete content and requests a retry at the current target. It caches at most one decoded asset in endpoint memory, rechecks rights before every scheduled fragment and bounds fragments by both descriptor/recipient authorization and rights expiry. The sample cursor preserves continuous fragment boundaries without rounding each boundary to a whole millisecond.

The resolver must return descriptors authenticated together with their manifests through the E2EE parent channel, with current recipient membership checked. Its five-minute maximum authorization lifetime is a ceiling, not a requirement to retain permission that long. The rights adapter returns a short-lived explicit permission with an expiry; a boolean from a public service is insufficient. The waveform decoder remains endpoint-only and currently supports the bounded RIFF/WAVE subset documented by the media module.

Call `interrupt` before output-route or lifecycle changes and before rejoining after a paused clock; call `close` when leaving. These cancel delivery, wipe the cached PCM, clear scheduled output and advance the operation generation. An old download or permission result cannot rearm output or stop a newer generation. Permission, transport, authentication and timeline errors stop the current generation. A trusted time adapter must be monotonic within the session.

Integration tests exercise real encrypted packaging/decryption, current-position joins, continuous queues, broadcaster-defined asset changes, slow delivery, rights expiry, scope/metadata/tamper rejection and cancellation races. The sink and parent-channel adapters in those tests are doubles. No native-device, browser-interoperability, calibrated-output or deployed E2EE channel claim follows from these tests.
